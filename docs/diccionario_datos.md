# Diccionario de datos — únicamente de la demostración sintética

## facturacion.csv
| Campo | Tipo lógico | Descripción |
|---|---|---|
| id_factura | Texto | Identificador ficticio único de factura |
| fecha_emision | Fecha | Fecha ficticia AAAA-MM-DD |
| cliente_id | Texto | Identificador anónimo sin empresa real |
| ejecutivo_id | Texto | Clave del ejecutivo ficticio |
| linea_producto | Texto | Categoría de producto de prueba |
| monto_usd | Numérico | Importe inventado en USD |

## cuotas.csv
| Campo | Tipo lógico | Descripción |
|---|---|---|
| ejecutivo_id | Texto | Identificador ficticio del ejecutivo |
| mes | Texto AAAA-MM | Periodo mensual |
| cuota_usd | Numérico | Meta comercial ficticia |

## oportunidades.csv
| Campo | Tipo lógico | Descripción |
|---|---|---|
| id_oportunidad | Texto | Identificador de oportunidad ficticio |
| ejecutivo_id | Texto | Identificador de vendedor de prueba |
| mes | Texto AAAA-MM | Periodo |
| cliente_id | Texto | Identificador de cliente inventado |
| estado | Texto | Estado ficticio del pipeline |
| valor_estimado_usd | Numérico | Valor estimado de demostración |
| probabilidad_cierre | Numérico [0,1] | Probabilidad simulada |

**Todo el contenido es ficticio y no representa personas, clientes, cifras ni operaciones reales.**
