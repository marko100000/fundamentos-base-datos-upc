# Publicación segura en GitHub

- No publiques `.pbix` originales sin revisar el modelo y los datos importados: pueden contener registros y conexiones privadas.
- No subas CSV o Excel reales con clientes, RUC, trabajadores, precios, comisiones, facturación, emails o teléfonos.
- No incluyas capturas internas, logos, documentos de la empresa ni enlaces/QR de Power BI sin autorización.
- No publiques contraseñas, usuarios reales, cadenas de conexión, tokens ni ficheros `.env`.
- No copies directamente los PDFs de enunciados o documentos grupales sin confirmar los permisos de publicación.
- Comprueba cada archivo descomprimido antes de hacer clic en **Commit changes**.
- Este repositorio incorpora solamente una demo creada con datos artificiales.
